# agent-config

Tool-use and prompt guard hooks for Claude Code, Codex, and Cursor. Python 3.9+ standard library only, no network.

## Layout

- `hooks/`: the guard. Entry points `guard-bash.py`, `guard-files.py`, `guard-codex.py`, `guard-cursor.py`, `guard-prompt.py`; rules in `guard_*.py`. Runtime files only.
- `tests/cases.py`: block and allow cases. `tests/ordinary.txt`: real commands that must never be refused.
- `tests/redteam-candidates.txt`: known bypasses, each with a reason.
- `install.sh`, `uninstall.sh`, `bin/agent-config.js`, `scripts/install_settings.py` (Claude Code), `scripts/install_hooks_json.py` (Codex and Cursor), `scripts/migrate-legacy.sh`: installer.
- `docs/guard-coverage.md`: generated by `scripts/guard-coverage`.

## Rules

- Every new block rule needs a paired allow case for the nearest legitimate command.
- A refused ordinary command goes in `tests/ordinary.txt` first, then gets fixed.
- Hooks fail open on internal errors. Keep it that way.
- Smallest change that works. Comments are one line, only for a non-obvious why. No em dashes.
- Commits: `type: description`, lowercase, imperative, under 72 characters.
- Run `./scripts/gates --no-perf` before a PR. CI runs the full gates, which take minutes.

## Releasing

1. In a PR: bump `VERSION` and `package.json`, add a `CHANGELOG.md` entry. Merge.
2. `gh release create vX.Y.Z --target main --title vX.Y.Z --notes-file <notes>`

The publish workflow runs the gates and publishes with npm trusted publishing. There is no token.

Do not:

- Run `npm publish`, `npm trust`, or `npm deprecate` locally. They need a typed 2FA code and this account uses a passkey. Do package settings on npmjs.com in a browser.
- Add `NODE_AUTH_TOKEN` or an `NPM_TOKEN` secret to the workflow.

If publishing fails:

- `404` on `PUT` means the login was rejected, not a missing package. Check npmjs.com, package settings, Trusted Publisher: user `sid-thephysicskid`, repository `agent-config`, workflow `publish.yml`.
- `EOTP` means a token is being used instead of trusted publishing.
